Etapa 1

Antes de responder

Nos primeiros minutos da conversa você descobre com quem está falando, que tipo de pedido é e quanto ele é urgente.

A Coplan atende várias prefeituras, cada uma com sua base de dados, e cada prefeitura usa vários sistemas (Tributário, Contábil, RH, Educação, Administrativo). Sem esses três dados, o N2 não sabe nem onde procurar.

Assim não
O sistema está dando erro, o cliente pediu urgência.
Assim sim
Município: Prefeitura de Exemplo
Usuário: Joana Lima, Setor de Tributos
Módulo: Tributário

Cada tipo vai para um caminho diferente. Dúvida você resolve na hora. Erro vai para o N2. Configuração costuma ser um parâmetro do cliente. Melhoria vira pedido para o produto. Classificar errado manda o chamado para a fila errada. Teste você mesmo:

Etapa 2

Antes de escalar para o N2

Se você não resolveu, o chamado sobe. Antes de subir, ele precisa ter tudo o que o N2 vai perguntar.

Reproduzir é fazer o problema acontecer de novo, de preferência em homologação. Se acontece com você, é provável que seja do sistema. Se só acontece com aquele usuário, a pista muda: permissão, cadastro ou computador dele. As duas respostas ajudam o N2.

Assim não
Não testei, o cliente disse que dá erro.
Assim sim
Reproduzi em homologação com a inscrição 01.02.003.0045: o erro aparece.

ou

Não reproduzi: com meu usuário de teste funciona. Só acontece com o usuário da Joana.

Os passos são a receita para o N2 chegar no mesmo lugar que o cliente. O esperado e o obtido mostram a diferença que é o problema. Se o N2 seguir seus passos e não ver o erro, faltou passo.

Assim não
Não emite a guia.
Assim sim
Passos:
1. Entrar no Tributário
2. Abrir Emissão de guia de IPTU
3. Informar a inscrição 01.02.003.0045
4. Clicar em Emitir

Esperado: abrir o PDF da guia 2026.
Obtido: aparece "Erro inesperado" e nada abre.

O caminho de menu acima é um exemplo. Use os nomes exatos que aparecem na tela.

Um print mostra coisas que o cliente nem percebeu: a tela, o usuário logado, o endereço, a mensagem inteira. Tire o print da tela toda, não só do pedaço com o erro.

Assim não
Print recortado só com "Erro inesperado".
Foto da tela tirada com o celular, torta e com reflexo.
Assim sim
Print da janela inteira, com:
- endereço (URL) visível
- usuário logado visível
- mensagem de erro completa
- relógio do computador, se der

A tela mostra "Erro inesperado", mas por trás o navegador conversou com o servidor e recebeu uma resposta com o motivo real. Você vê essa conversa apertando F12 e abrindo a aba Network (ou Rede). Linha vermelha é o que importa. Clique nas linhas abaixo:

ElementsConsoleNetworkApplication
NameStatusMethodTypeTime
Selecione uma linha para ver os detalhes.

Dica: 2xx deu certo. 4xx costuma ser algo do pedido (dado faltando, sem permissão). 5xx é falha no servidor e quase sempre vai para o N2.

Tela, endereços e resposta são fictícios.

O servidor guarda um registro (log) de tudo o que acontece, mas são milhares de linhas por minuto. Com a hora exata, o N2 acha o erro em segundos. Com "ontem à tarde", pode levar horas.

Assim não
Aconteceu ontem à tarde.
Assim sim
07/10/2026 às 14:12 (horário de Cuiabá).
Aconteceu 3 vezes entre 14:05 e 14:15.

Se você não escreve o que já testou, o N2 vai testar tudo de novo. Cada tentativa registrada economiza tempo de quem vem depois e mostra o seu trabalho.

Assim sim

- Testou no Chrome e no Edge: mesmo erro
